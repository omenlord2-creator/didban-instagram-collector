# DIDBAN Instagram Collector

A public-source ingestion project for collecting publicly accessible Instagram post metadata and media references from approved news accounts.

## Scope
- Public posts only; no Instagram login, passwords, session cookies, or private-account access.
- Preserve exact post URLs and captions when publicly available.
- Deduplicate collected posts.
- Mark items as not ready when the post URL or required media metadata is unavailable.
- Keep publishing to Bale disabled until the collector output and a documented Worker integration are verified.
